AI を使う準備をしましょう

このアプリは、パソコンで AI エージェントを動かすためのソフトをまとめて入れます。 ターミナルでコマンドを打つ必要はありません。

  • Claude Code と Codex … ファイルを読み書きしながら作業してくれる AI エージェント
  • Paseo … それらを画面から（スマホからも）操作するアプリ
  • Git・GitHub CLI・Node.js など、AI エージェントがよく使う道具もまとめて入れられます

所要時間は 5〜10 分ほどです。インターネットにつながった状態で進めてください。
